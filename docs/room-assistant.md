# Room Assistant

The Room Assistant is an opt-in storefront experience for Shopify furniture merchants. It provides three entry points: preview the current product through the existing Tryora flow, request grounded product recommendations from a room photo, and ask store questions in a bounded chat session.

## Merchant controls

The assistant is disabled by default. Merchants enable and configure it from **Tryora > Room assistant**. Settings include page-type visibility, exact product and collection exclusions, greeting text, launcher label, position, and colour. Exclusions take precedence over page-type visibility.

Settings are stored in the existing `Appearance.copy` JSON object under the `assistant` key. This feature adds no Prisma models, migrations, or startup database operations.

## Provider configuration

The server requires both values before the assistant can appear:

```env
OPENAI_API_KEY=...
OPENAI_ASSISTANT_MODEL=gpt-4.1-mini
OPENAI_ASSISTANT_PRIVACY_ACKNOWLEDGED=true
```

`OPENAI_ASSISTANT_MODEL` is optional and defaults to `gpt-4.1-mini`. The separate privacy acknowledgement is required because recommendation requests can send a normalized room image and a bounded subset of merchant catalogue and policy data to OpenAI. Requests use the Responses API with `store: false`.

## Grounding and safety boundaries

- Catalogue data comes only from enabled, ready `ProductPreviewConfig` records and live Shopify Admin product data.
- Recommendations contain exact, live Shopify variant IDs and selected option values.
- `availableForSale` is checked from Shopify; inventory is never inferred from location counts.
- Search results and model-returned IDs are validated against the server-built candidate set.
- Every recommended candidate is passed through `resolvePreviewProduct`; stale or missing approved references are omitted.
- Product links include the exact variant ID. The assistant never substitutes another variant, fabric, colour, size, or reference.
- Policy answers are grounded in Shopify shop policies when available.
- Room photos and chat history remain in browser memory. The server does not persist them, and assistant messages do not consume preview credits.

## Limits

Each request receives a bounded chat history, up to 25 configured products, up to 600 exact candidates, and a limited policy summary. Assistant traffic is rate-limited per visitor and shop. The browser validates and compresses room photos before upload; the server applies its own upload limit and image normalization.

The assistant does not make unsupported external product-option providers available. A recommended product opens its exact Shopify variant page, where the existing strict Tryora preview validation remains authoritative.

## Release verification

Run from the repository root:

```sh
npm test
npm run typecheck
npm run build
git diff --check
```

The storefront bundle at `shopify-app/extensions/tryora-theme/assets/tryora.js` is generated by `npm run build` and must not be edited manually.
